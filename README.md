Este projeto tem como objetivo analisar dados do Campeonato Brasileiro utilizando Python, exibindo tabelas dinâmicas, gráficos interativos e diversos indicadores estatísticos para acompanhar o desempenho dos times ao longo da competição.

A aplicação permite explorar informações como:

⚽ Saldo de gols
🛡️ Gols sofridos
🔥 Desempenho por rodada
📈 Progresso do campeonato
🏆 Probabilidade de título de cada time
📊 Classificação atualizada
📉 Comparações por métricas específicas
🔎 Dados detalhados por equipe

Tudo isso apresentado de forma visual e intuitiva através de dashboards interativos.

🚀 Tecnologias Utilizadas

Python 3.x
Pandas para manipulação dos dados
Plotly / Plotly Express para geração dos gráficos
Streamlit para interface e dashboards interativos
Requests + BeautifulSoup (caso use scraping para buscar dados)

📁 Funcionalidades do Projeto
✔️ 1. Coleta e Limpeza de Dados

Leitura de tabelas do campeonato (via scraping ou CSV);
Tratamento e reorganização das informações;
Normalização de nomes, rodadas e estatísticas;

✔️ 2. Dashboards Interativos

Gráficos de linha, barras, pizza e indicadores;
Atualização automática conforme os dados mudam;
Filtros por time, rodada e tipo de análise;

✔️ 3. Tabelas Dinâmicas

Tabela do campeonato estilizada;
Ordenação por pontos, saldo, gols marcados etc;
Destaques para vitórias, empates e derrotas;

✔️ 4. Métricas Avançadas

Projeção de pontuação;
Probabilidade de título (baseada em simulações);
Evolução rodada a rodada;

✔️ 5. Comparativos Entre Times

Comparação direta de desempenho;
Análise lado a lado de métricas selecionadas.
